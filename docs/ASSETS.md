- `art/ui_brushes.txt` (research dump), `art/textures/sizes.txt`.
- Editor stand-ins in `Content\Materials\UI_Textures` (flat 1x1 textures used only so the paste resolved). Removed by hand in the editor, not packed.

## Runtime-only game reference
- `/Game/Blueprints/Widgets/Display/WBP_FleetShipEntry` is used at runtime as the ship hologram widget class. Nothing is copied from it.

## Regenerate
1. `cd ue\MiningUnitUI\scripts`
2. `python -I extract_textures.py` (headers into art\textures), `python -I extract_item_icons.py` (items into art\items)
3. `python -I gen_paste.py` and `python -I gen_paste.py --flat` (paste files; both must print VALIDATION OK)
4. Editor: `scripts\make_assets.py` via UnrealEditor-Cmd imports the PNGs into Content\MiningUnitUI\Art.
5. `python -I ..\..\..\tests\test_asset_refs.py` must pass.
