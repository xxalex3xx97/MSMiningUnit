# WBP_MiningUnit: one-paste build

Pastes the whole SPEC.md tree (2556 widgets, 1700 named Is Variable) into `WBP_MiningUnit` in UE 5.7.4.
Generated by `scripts\gen_paste.py`. Output: `paste\WBP_MiningUnit_tree.txt`.

## Steps

1. Put the text on the clipboard. In PowerShell:
   ```
   Get-Content -Raw "<repo>\ue\MiningUnitUI\paste\WBP_MiningUnit_tree.txt" | Set-Clipboard
   ```
   (Or open the .txt in Notepad, Ctrl+A, Ctrl+C.) Do not copy anything else before step 4.
2. Open `<repo>\ue\MiningUnitUI\MiningUnitUI.uproject` in UE 5.7.4.
3. Content Browser: `Content\MiningUnitUI\WBP_MiningUnit`, double-click to open the Widget Designer.
4. Empty the root first:
   - In the Hierarchy panel, if a `CanvasPanel_0` (or any root) exists: click it, press Delete.
   - Click empty space in the Hierarchy so NOTHING is selected.
   - Why: paste goes INSIDE the selected widget. With a selection, the tree nests wrongly.
5. With the mouse over the Hierarchy panel, press Ctrl+V.
6. Check the Hierarchy: `Root (Canvas Panel)` > `Panel (Border)` > `Row_Cols` > three `Row_Win*`, the centre header holds `Txt_Title` and `Row_CloseCap` > `Btn_Close`, PageSwitcher (Page_Ship, Page_Items, Page_Operation, Pnl_PageLog), TabBar has 4 tabs (Btn_TabLog = Log), Txt_Status. Left column also holds `Pnl_Fleet` (Fleet Control box) with `Row_RemoteRow` (`Sel_Remote` + `Btn_RemoteAll`). Centre: `Pnl_AllWarn` (collapsed) sits between TabBar and PageSwitcher. `Root` has a 2nd child `Pnl_Modal` (collapsed).
7. Compile, then Ctrl+S. Output/Message Log must show no red errors.
8. Continue with `EDITOR-STEPS.md` from step 5 (close editor, cook, pack, install with game closed).

## If it fails

- Ctrl+V does nothing: clipboard lost or not text. Redo step 1, copy again, and make sure the Hierarchy has focus.
- "Paste operation on widget cancelled" or a "slot can only hold one widget" notice: something was selected (a Border/Button). Click empty space, retry.
- Tree landed under `CanvasPanel_0`: Ctrl+Z, delete the default root (step 4), paste again.
- Partial or wrong tree: Ctrl+Z, do not hand-patch. Send the Message Log lines (Window > Message Log > Blueprint / UMG) and the result of step 6.
- Paste rejected in every case: fall back to hand build per `SPEC.md` + `EDITOR-STEPS.md` step 4. No split-paste mode exists yet.
